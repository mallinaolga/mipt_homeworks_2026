Проект реализует простой чат с LLM: пользователь вводит сообщения в терминале, приложение отправляет их модели, получает ответ и сохраняет историю диалога. Также поддерживается системный промпт, ограничение контекста, очистка истории, вставка содержимого файлов в сообщение и обработка больших файлов по частям.


В проекте реализовано: консольный чат с LLM, работа через OpenAI-compatible API, системный промпт, хранение истории сообщений, ограничение контекста по количеству сообщений, ограничение контекста по количеству символов, автоматическое удаление старых сообщений при превышении лимита, команда очистки истории, команда выхода из приложения, потоковый вывод ответа модели, вставка содержимого файла прямо в сообщение, обработка больших файлов чанками, ручной и автоматический режим обработки чанков, базовая валидация конфигурации. 


Запуск
Перед запуском нужно установить зависимости и настроить параметры подключения к LLM.

1. Установите зависимости:

```bash
python3 -m pip install -r requirements.txt

2.Создайте .env на основе примера:
cp .env.example .env

3.Заполните .env:
API_KEY=your_api_key_here
API_HOST=https://api.openai.com/v1
MODEL_NAME=gpt-4o-mini
LIMIT_MESSAGES=10
LIMIT_CHARS=8000
TEMPERATURE=0.7
SYSTEM_PROMPT=Ты полезный ИИ-ассистент. Отвечай ясно, вежливо и по делу.

4.Запустите приложение:
python3 main.py
